## 🚀 Flagship Projects

### 🌱 AgriVision – Smart Agriculture Intelligence Platform

**AI-Powered Crop Recommendation & Plant Disease Detection**

- Developed a Top-3 crop recommendation system using soil NPK, pH and weather parameters.
- Integrated a 38-class CNN-based plant leaf disease detection system.
- Integrated real-time weather, 7-day forecasts, crop-risk alerts and district-level soil data.
- Built a multilingual AI agricultural assistant with voice interaction in English, Hindi and Punjabi.

**Technologies:** Python · Machine Learning · CNN · Streamlit · Weather API · NLP

[Explore my GitHub repositories](https://github.com/tanmayjhalani1-ui?tab=repositories)

### 🎬 VINDHYA – AI-Powered Generative Teaching Platform

**Transforming Learning Through Generative AI and Video Generation**

- Engineered a five-stage LLM pipeline for knowledge extraction, teaching-script generation, scene decomposition, instructional visual planning and video-prompt synthesis.
- Applied prompt engineering for structured scenes and visual consistency.
- Optimized LTX-Video 2B for inference on a 16-GB NVIDIA T4 GPU.
- Used GGUF Q5_K_M, 4-bit NF4 T5-XXL, FP16, VAE tiling, model caching and deterministic generation.
- Built supporting lesson-generation capabilities for narration, notes, topic-based quizzes, simplified explanations, doubt-solving and learning reports.

**Technologies:** Generative AI · LLMs · Prompt Engineering · LTX-Video · NLP · GPU Optimization
